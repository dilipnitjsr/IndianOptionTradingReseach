# Paper

*A Market-State-Aware Framework for Algorithmic Options Trading in Indian Derivatives Markets*

- `figures/`: plots produced by `simulation/figures.py` for the paper.
- `manuscript/`: the manuscript sources (LaTeX and Word). This folder is ignored by git, so the unpublished draft stays out of the public repository. Remove `paper/manuscript/` from `.gitignore` to track it.

Section and equation numbers used in the code comments refer to the IEEE-format draft.
